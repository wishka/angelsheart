# Ангел-Хранитель — Платформа взаимопомощи

> Разработка, ветки, проверки и выкладка — [docs/CICD.md](docs/CICD.md) и [CONTRIBUTING.md](CONTRIBUTING.md). Подготовка сервера — [deploy/README.md](deploy/README.md).

## 📖 О проекте

«Ангел-Хранитель» — это веб-платформа для взаимопомощи, где пользователи могут:
- Переводить деньги друг другу напрямую
- Создавать сборы средств на важные цели
- Жертвовать в сборы других пользователей
- Управлять своими финансами в личном кабинете

Проект построен на **Django** с использованием **Django REST Framework (DRF)** для мобильного API, имеет полноценную админ-панель и систему безопасности.

## 🔄 Процессы в системе

### 1. Регистрация пользователя
Пользователь → Заполняет форму → Принимает согласия → Подтверждение → Создание баланса

text

**Шаги:**
1. Пользователь заполняет форму регистрации (имя, email, пароль)
2. Обязательно принимает три согласия:
   - Политика конфиденциальности
   - Пользовательское соглашение
   - Политика использования cookies
3. Система фиксирует IP-адрес, User-Agent и время согласия
4. Автоматически создается баланс пользователя (0 ₽)
5. Выполняется автоматический вход в систему

**Хранение данных:**
- Пароли хэшируются (PBKDF2)
- IP-адреса логируются
- Согласия сохраняются в БД с версионированием

### Схема безопасности перевода
sql
BEGIN TRANSACTION;
    -- 🔒 Блокировка строк балансов
    SELECT * FROM balance WHERE user_id = sender FOR UPDATE;
    SELECT * FROM balance WHERE user_id = receiver FOR UPDATE;
    
    -- ✅ Проверка достаточности
    IF sender.balance >= amount THEN
        -- 📤 Обновление балансов
        UPDATE balance SET amount = amount - amount WHERE user_id = sender;
        UPDATE balance SET amount = amount + amount WHERE user_id = receiver;
        
        -- 📝 Запись транзакции
        INSERT INTO transaction (sender, receiver, amount, status);
    END IF;
COMMIT;
