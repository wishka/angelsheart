Пользовательское соглашение

1. Термины и определения

1.1. «Сервис» — онлайн-платформа «Ангел-Хранитель», предоставляющая возможность совершения денежных переводов между пользователями.

1.2. «Пользователь» — физическое лицо, зарегистрированное в Сервисе и принявшее условия настоящего Соглашения.

1.3. «Перевод» — добровольное перечисление денежных средств от одного Пользователя другому.

2. Предмет соглашения

2.1. Сервис предоставляет Пользователю возможность совершать денежные переводы другим Пользователям.

2.2. Сервис не является финансовым посредником и не несет ответственности за законность операций Пользователей.

3. Комиссия сервиса

3.1. Сервис взимает комиссию за использование платформы для сборов средств.

3.2. Размер комиссии составляет 3% от суммы каждого пожертвования в сбор.

3.3. Комиссия удерживается автоматически в момент совершения пожертвования.

3.4. Средства, полученные в качестве комиссии, направляются на:

  • Поддержание работоспособности сервиса
  • Обеспечение безопасности и защиты данных
  • Разработку новых функций и улучшение платформы
  • Техническую поддержку пользователей
  • Продвижение платформы и привлечение новых пользователей

3.5. Сервис обязуется использовать средства комиссии исключительно на развитие платформы.

3.6. При прямых переводах между пользователями (не через сборы) комиссия не взимается.

4. Права и обязанности пользователя

4.1. Пользователь обязуется:

  • Предоставлять достоверную информацию при регистрации
  • Не использовать Сервис для незаконных операций
  • Не осуществлять переводы с целью отмывания денег
  • Не нарушать законодательство РФ

5. Ограничение ответственности

5.1. Сервис не несет ответственности за:

  • Последствия добровольных переводов между Пользователями
  • Потерю данных при форс-мажорных обстоятельствах
  • Действия третьих лиц при нарушении Пользователем мер безопасности

6. Запрещенные операции

Запрещается использование Сервиса для:

  • Переводов, связанных с незаконной деятельностью
  • Финансирования терроризма и экстремизма
  • Азартных игр и ставок
  • Обналичивания денежных средств

7. Разрешение споров

7.1. Споры между Пользователями решаются путем переговоров.

7.2. Сервис не выступает арбитром в спорах между Пользователями.

8. Изменение условий

8.1. Сервис оставляет за собой право изменять условия Соглашения.

8.2. Изменения вступают в силу с момента публикации на сайте.
